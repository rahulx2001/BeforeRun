# Core features — implement during the hackathon

This directory is intentionally a placeholder. No Gatekeeper application code has been copied here.

The following core components must be developed during the event:

- public GitHub URL/ref validation, commit resolution, and bounded source retrieval
- Node setup entry points and referenced helper inspection without execution
- optional comparison with a selected baseline commit
- the live Kimi K3.1 Pro investigation loop on Cerebras
- evidence and citation validation
- findings, uncertainty, and the investigation trace

GitHub repository review is the selected first workflow. npm registry input and other
package adapters follow after repository review is implemented and verified. Python
setup review is conditional on dedicated event-time validation; it is not required for
the first demo. See the [research brief](../../../docs/RESEARCH_BRIEF.md).

See [the event plan](../../../docs/HACKATHON_PLAN.md) and
[repository review plan](../../../docs/REPOSITORY_REVIEW_PLAN.md) for the planned order
and acceptance checks.
