Scope, privacy & assumptions

Root public GitHub source only. Blank revisions resolve the default branch once; a baseline is a comparison, not a trusted clean version. Selected code and questions go to a cloud model through OpenClaw. Registry dependencies, downloads, native binaries, full application reachability, and install protection are outside this review.

One process holds jobs in memory for up to one hour. Restarting or expiry loses them; export only what you deliberately want to retain.

We read selected source as data; we do not run it.
